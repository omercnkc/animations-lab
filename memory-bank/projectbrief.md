# Project Brief: Animation Lab & Interactive Playground

## Overview
Animation Lab is a modern, interactive web showcase and playground platform for both Web (React, Framer Motion, Vanilla CSS) and Mobile (React Native, Reanimated v3) animations.

## Core Goals
- **Dual-Platform Showcase**: Side-by-side or tabbed Web and Mobile animation implementations.
- **In-Browser Interactive Playground**: "Try it Yourself" live code editor (Sandpack for Web, Expo Snack Embed for Mobile).
- **Copy-Paste Ready**: Seamless code snippets, CLI installation commands, and zero boilerplate friction.
- **Modern Aesthetic**: Dark mode by default, glassmorphism, micro-animations, fast responsive performance.

## Tech Stack
- Framework: Next.js (App Router, TypeScript)
- Styling: Tailwind CSS & Vanilla CSS
- Web Playground Engine: `@codesandbox/sandpack-react`
- Mobile Playground: Expo Snack Embed
- Animation Libraries: Framer Motion (Web), React Native Reanimated (Mobile)
- Icons: Lucide Icons
- Hosting: Vercel
- GitHub Repository: https://github.com/omercnkc/animations-lab
