# Product Context

## Why Animation Lab Exists
Developers often struggle to find modern, realistic micro-interactions and transitions that are ready to use across both Web (React) and Mobile (React Native) ecosystems. Most animation showcases only provide video previews or static GIFs without editable live code.

## Problems Solved
1. **Lack of Live Experimentation**: Video previews don't let developers tweak springs, timing curves, or props without cloning a repo.
2. **Platform Disconnect**: Web and Mobile codebases usually live in separate silos; finding equivalent animations for both React and React Native is difficult.
3. **Complex Setup**: Setting up local sandbox environments just to test a single button animation takes too much time.

## User Experience Goals
- Instant preview and fluid in-browser live code editing (Sandpack / Expo Snack).
- One-click copy for component code and npm install commands.
- Sleek, dark-themed, ultra-responsive gallery interface with smooth transitions.
